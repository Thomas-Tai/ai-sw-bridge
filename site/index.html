Driving real SOLIDWORKS from an AI agent — and why it's hard

1. The problem

AI agents can already emit “CAD,” but that usually means a dead STEP or mesh dump from a throwaway kernel — geometry with no history, nothing you can open and keep editing in the tool you actually design in. ai-sw-bridge starts from a different premise: drive the CAD system you already run, and keep the feature tree native.

2. Propose → approve → execute (human-gated safety)

Every change follows the same three-step gate: the agent proposes a spec, you review and approve it, and only then does it execute against your live SOLIDWORKS seat. Nothing runs silently — every step is visible before it touches your model.

3. Native editable feature tree vs. foreign STEP

The output is a real .SLDPRT feature tree you keep editing — change a dimension, rebuild, exactly like anything you built by hand. A STEP import isn't like that: you can only push its faces around, not edit the history that made them.

4. The real kernel walls

This isn't friction-free, and we say so plainly: a whole class of features — lofts, ribs, wraps, combines and the like — can't be driven out-of-process, so the bridge refuses them cleanly rather than emit a broken part; and in dimensioned mode a handful of SOLIDWORKS dimension dialogs still need a human tick before they'll proceed. These walls are labeled honestly, not hidden — see the full, current list in Known Limitations.

5. Try it with no seat

You don't need SOLIDWORKS installed to start. Author and lint a real spec offline — schema, references, locals, DFM lint — with zero license (Tier A) via the 5-minute Quickstart. Building actual geometry is Tier B, and that's where a SOLIDWORKS seat becomes required.

AI + SOLIDWORKS — which fits your job?

Two different things an AI agent can hand you. Neither is universally better — which one fits depends on what you need to do with the output next.

Real seat, native feature tree

  • Output: a live .SLDPRT / .SLDASM in your own SOLIDWORKS
  • Editing: change a dimension and rebuild, same as hand-built work
  • Requires: a running, licensed SOLIDWORKS 2021+ seat (Tier B)
  • Fits when: you're going to keep iterating on this part

Throwaway-kernel → STEP dump

  • Output: a static STEP or mesh file, no feature history
  • Editing: only by pushing faces around; design intent is gone
  • Requires: no CAD seat at all
  • Fits when: you need a one-off shape to reference or print once
